# 「心愿单流」最终方案：荒诞规则 × 吉利愿望 × 克制催泪

> 一句话：把"地府打工人"换成"愿望打工人"——KPI/差评/加班的荒诞规则不变，外壳换成吉利的"心愿单系统"，用"克制式催泪"做记忆点，用爽点做基本盘。

---

## 一、打动人的机制（可执行设计，非空话）

### 核心情感设计：「愿望=遗憾」

每个愿望背后都是一个遗憾——读者许过愿、有过遗憾，这是普世共情。
**愿望类型谱系**（每类都有泪点潜力）：
| 类型 | 例子 | 泪点机制 |
|---|---|---|
| 遗憾型 | 想对爸爸说句"对不起" | 未说出口的话 |
| 亏欠型 | 想给母亲补过一次生日 | 迟到的补偿 |
| 时间型 | 想找回小时候弄丢的玩具 | 物是人非 |
| 孤独型 | 想有人陪我过六十岁生日 | 被遗忘的角落 |
| 牺牲型 | 用十年记忆换女儿婚礼不下雨 | 无声的付出 |

### 每卷一个「泪点单元」（S 级愿望=卷级催泪事件）
- 第 1 卷泪点：87 岁老人"最后一次许愿"修旧照片，林渡修好后发现照片背面写着"想再看看老伴年轻时的样子"
- 第 2 卷泪点：老人六十大寿愿望，准备了两副碗筷，儿女都在国外
- 第 3 卷泪点：单亲妈妈 S 级愿望——代价是她的"十年记忆"，林渡发现她忘了的事是"自己曾经也想过自杀"
- 主角自己的泪点（贯穿）：**员工不能为自己许愿**——他有一个遗憾（父亲十年前失踪，最后一次通话说"明天陪你过生日"），他帮全世界圆梦，自己的梦没人接

### 克制式催泪写作规则（避免鸡汤化）
1. 哭点永远用"动作/物件"承载：碗筷、旧照片、一条没发出去的消息
2. 情绪最高点**不写哭**，写"他走了两步，又退回来，把伞放在门口"
3. 每个泪点单元后面紧跟一个爽点单元（眼泪不能超过 3 章）
4. 配角不是工具人：泪点单元里的配角要有"独立生活感"（不是为了哭而哭）

### 爽泪配比（番茄基本盘）
```
70% 爽点（规则博弈/打脸贪心许愿者/愿力翻倍/升级）
20% 推进（主线：系统真相/父亲愿望）
10% 泪点（每卷 2-3 个高光泪点，绝不连续）
```

### 风险修正（最重要的审查结论）

⚠️ **纯温情在番茄男频没有爆款先例**（搜索验证：番茄治愈向只有女频言情/双男主，男频无验证先例）→ **泪点只能做 10% 的锦上添花，70% 必须是爽点**。若泪点占比失控，书会"温死"（读者要的是情绪出口，不是感动教育）。
